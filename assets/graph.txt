# PSCT demo on the man / bird / john knowledge graph.
#
# We start with no hand-written rules. Deduction alone derives nothing.
# psct:enable turns on the closed loop:
#   1. Deduction fixpoint → 0 new chains (no rules)
#   2. Analogy step       → enumerate (λ₁, λ₂) chain compositions
#   3. Induction step     → for any (λ₁, λ₂) with support ≥ θ and
#                            cex-ratio ≤ ε, synthesise a rule
#       IF X→λ₁→Y AND Y→λ₂→Z THEN X→λ₂→Z
#   4. Deduction re-fires with the induced rule → new chains appear.
#
# Run from a terminal to see the trace, or look at the induced-rules
# panel in the sidebar.

psct:enable
psct:theta=3
psct:epsilon=0.0

hover:john

man->will->talk
bird->will->fly
john->isa->man
man->isa->animal
bird->isa->animal
animal->will->die
